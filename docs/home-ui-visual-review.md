# 首页视觉原型与验证

按参考图实现桌面外壳、首页、底部播放条、音乐库和设置页。移动端继续使用原有首页和播放条。

## 数据边界

- 继续聆听和最近添加优先展示现有队列、媒体库数据；空列表使用设计样例。最近添加沿用原有取数逻辑，本轮不新增播放历史或统计服务。
- 常听的艺术家、心情歌单、音乐时刻和右侧数量为占位。点击尚未接入的卡片会显示占位提示，不创建虚构的播放请求。
- 占位集中于 `lib/ui/pages/home/home_placeholders.dart`，不会写入数据库。素材和提示词见 [素材记录](home-ui-assets.md)。
- 实际首页继续播放、歌曲点击和底栏控制调用现有播放器；搜索提交到媒体库。底栏的歌曲信息、进度、音量和音频格式来自真实状态。

## 实现边界

`DesktopShell`、`HomePage` 和 `NowPlayingBar` 连接窗口、Riverpod 与播放操作；`DesktopFrame`、`HomeView` 和 `DesktopPlayerBar` 负责表现。固定数据预览使用这三个生产组件，避免再维护一份仅供截图的布局。

宽窗口展示参考图的多栏结构；较窄窗口减少每排卡片数量、隐藏右侧附属卡片并纵向滚动，底部播放条固定。主验证尺寸为 1536×1024，另覆盖 1280×800、1024×720、900×700。

## 自动截图

在 `apps/stellatune` 目录运行：

```powershell
.\tool\visual_review.ps1
```

测试固定字体、图片、文案、时间、视口及 DPR，输出 `build/visual-review/` 下的 PNG。覆盖四种窗口尺寸、卡片悬停、暂停、窄窗口滚动、长标题、缺失封面和 125% 字体。测试检查布局异常与播放按钮交互；截图用于进一步目视检查，不等于已建立像素差异回归基线。

Windows 原生渲染截图：

```powershell
.\tool\visual_review.ps1 -Native
```

原生入口不初始化 Rust、数据库、插件或音频设备。启动窗口后自动保存 `home-windows-native.png` 并退出。截图来自 Flutter 渲染树，可验证原生字体与渲染效果，不包含系统窗口边框。Windows 的客户区尺寸可能略小于请求的窗口尺寸。

交互式预览：

```powershell
flutter run -d windows -t tool/visual_preview.dart
```

预览中的播放按钮、歌曲选择、进度条和音量只改变演示状态；侧栏不打开真实业务页面。窗口拖动、关闭、最小化和最大化使用真实窗口操作。

预览会使用正常的 Debug 构建目录。回到实际应用使用 `flutter run -d windows -t lib/main.dart`，或通过 `flutter build windows --debug -t lib/main.dart` 恢复正常入口的构建产物。

## 后续视觉验证流程

1. 修改生产组件后运行脚本，确认测试通过并生成新截图。
2. 由助手读取截图，检查参考图对应的比例、留白、文字、图片裁切、悬停状态和各尺寸溢出情况。
3. 需要核验原生差异时运行 `-Native` 并读取其截图；生产应用的数据接入仍需单独验证。
4. 设计确认稳定后再建立 golden 基线；固定 Flutter 版本、平台和字体，避免将跨平台抗锯齿差异误判为布局变化。

当前没有把参考图片直接作为整屏 golden：参考图中的摄影素材与生成素材不同，整屏像素比较不能可靠衡量设计还原程度。

首页歌曲卡片使用完整方形封面，曲名和作者叠在底部。同尺寸封面副本以 sigma 3 模糊，再通过透明度蒙版从卡片高度 45% 至 82% 逐渐显现，羽化模糊层本身，避免矩形裁切的硬边。遮罩从透明渐变到约 22% 黑色，文字附带轻微阴影。继续聆听和最近添加都移除卡内播放按钮及进度条，点击整张卡片仍使用原有播放回调。

## 音乐库

音乐库沿用背景，提供歌曲、专辑、艺术家、文件夹四个分类，不添加“全部”、FLAC 或流派筛选标签。歌曲表格复用 TrackList 的播放、收藏、多选、右键菜单和虚拟滚动。表头与行共享列宽，小窗口隐藏专辑列，再隐藏格式列。

专辑按现有 album + artist 分组，艺术家按 artist 分组；数据来自当前媒体库查询结果，搜索也会影响分组。点击集合进入其歌曲列表，播放使用当前排序后的集合。当前模型没有 album artist、年份或独立艺术家头像，因此不展示年份，艺术家圆形图使用歌曲封面；缺失封面使用通用图标。尚未针对合辑的 album artist 做跨艺术家合并。

截图测试还覆盖音乐库两个尺寸、歌曲/专辑/艺术家视图、集合进入返回、播放回调和收藏。测试封面复用首页生成素材，仅存在于预览数据中。原生截图命令：

```powershell
.\tool\visual_review.ps1 -Native -Page library-albums
# 歌曲表格：-Page library
```

交互预览：`flutter run -d windows -t tool/visual_preview.dart --dart-define=VISUAL_PAGE=library-albums`。

## 设置页

设置页按外观、播放、音频、音乐库、插件、歌词分组，使用现有持久化与播放器回调。未添加当前没有对应功能的 ReplayGain、紧凑模式、自动匹配封面、淡入淡出时长等开关。音乐库卡片连接实际目录添加、移除和扫描操作。

宽窗口每行两个等高卡片，按该行实际内容较高的一张确定高度；窄窗口单列滚动。搜索按关键词筛选相关分组。截图测试验证三个窗口尺寸、成对卡片上下边界对齐、搜索与控件交互。

`SettingsVisualPreview` 使用固定演示值和共享的卡片、表单、外观及目录组件；其操作只改变预览状态。实际设置页继续调用原有服务，音频设备切换仍需用实际设备验证。

```powershell
.\tool\visual_review.ps1 -Native -Page settings
```

原生截图脚本先构建预览，再直接启动可执行文件，避免自动截图退出与 Flutter 调试服务连接之间的竞态。

## 固定主界面主题与播放详情取色

主界面提供暮色、雾蓝、石墨、星云四套暗色配色，以及暖阳、晴空（默认）、薰衣草、青瓷四套亮色配色，入口为设置 → 外观 → 主界面配色。选项以名称存入 Hive `desktop_theme`，重启后恢复；未知名称回退晴空。主题预设同时决定明暗，不随切歌或封面变化。已删除独立的主题模式选项及读写逻辑，旧的 `theme_mode` 值不再读取。应用根主题与弹窗也使用预设配色。

`lib/ui/theme/desktop_theme.dart` 集中定义背景两端、柔光、强调色、卡片、播放栏及前景文字的颜色字面量；调整配色直接修改对应配置。`ArtworkPalette.applyTo` 将这些颜色统一映射到内容、控件和弹出菜单的主题，固定主界面不调用封面取色函数。暮色、雾蓝、石墨和星云使用同色系深色半透明面板及浅色文字，四套亮色使用各自的浅色面板及深色文字。

音乐库、设置卡片及底部播放栏共享表面与前景颜色。歌曲表格保留贴边布局，降低普通行交替底色的强度，通过悬停和选择状态强调交互。下拉菜单显式使用当前主题的表面色，测试覆盖所有预设与不同的外层主题明暗，并检查实际弹出层像素与文字的对比度。

八套主题均接入柔化的背景图片，配置项 `backgroundAsset` 和 `backgroundTint` 分别控制图片与遮罩。亮色分别使用奶油米色、浅蓝、淡紫和鼠尾草绿背景，通过 `onBackdrop` 配置深色文字；暗色主题保持白色背景文字。素材及完整生成提示词见 [桌面背景素材](desktop-background-assets.md)。

播放详情单独订阅当前封面，在 96×96 图片上提取代表色并限制饱和度和亮度。支持本地缓存及队列中的文件、URL、数据封面；失败回退中性配色，旧曲目的异步结果不会覆盖新曲目。关闭详情页后释放取色订阅。背景过渡为 800 ms，仅在颜色变化时动画，桌面不再持续运行背景 shader；移动端保留原有背景实现。

视觉测试输出 `home-theme-{dusk,mist,graphite,nebula,sunroom,daylight,lavender,celadon}.png`、`settings-theme-{dusk,mist,graphite,nebula,sunroom,daylight,lavender,celadon}.png`，以及 `library-{songs,albums,artists}-{dusk,sunroom,daylight,lavender,celadon}-1536.png` 和暮色的 1024 宽度版本。额外检查主题选择即时生效、演示切歌不改变主界面颜色、设置持久化和详情取色异步竞态。`detail-palette-{forest,moon}.png` 使用真实详情内容布局与背景，不含原生标题栏、播放控制及业务控制器。

```powershell
.\tool\visual_review.ps1 -Native -Page home -Theme dusk
.\tool\visual_review.ps1 -Native -Page settings -Theme mist
```

交互预览可以在侧栏打开设置并切换配色；其选择仅影响演示状态。旧的 `home-palette-*` / `settings-palette-*` 截图来自已放弃的主界面取色方案，不作为当前验收结果。


## 首页主题横幅

八套主题分别提供配套横幅，右侧引言卡同步使用同套图片的局部构图。明暗主题分别使用浅色和深色文案，图片两侧遮罩保证阅读；继续播放按钮保持原有回调。素材路径与完整提示词见 [横幅素材记录](home-banner-assets.md)。主题预览和原生预览默认晴空，已保存的用户选择保持不变。
